## 关于代码里的「权威出处」注释

`shared/model/*.yaml`、`shared/mapping/*.yaml` 等契约文件的注释与 `contract_of` /
`source` 字段里，会出现形如 `docs/03-方案1设计（知识图谱+LLM）.md §7.2` 的出处标注。
这些标注指向**作者内部设计语料**中的对应文档；公开分发树里只随附上表三份，
因此这类标注中的其余编号在本仓库内**没有对应文件**——它们是溯源信息，不是可用链接。

如果要让这些标注全部可解析，需要把内部设计文档整体脱敏后再随附；
本仓当前的选择是「只带与代码强相关的三份 + 在此说明其余出处指向何处」。
